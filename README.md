# calculator
This calculator uses if...else conditions and try.. except statement blocks to prevent the errors made by the users inputs for the operation.

#🧮 
    ◙ It takes multiple arguments to do the arithmetic operations like addition subtraction multiplication division additionally i added the factorials.
#process  
  ◙ First it takes input as string format using while loop and check it is float or not, The floats are appended in the list which is created, If user enters string Then i added try and except statement block, To identify and except block execute automatically.
    ◙ This process as same as all other functions in the program.
    ◙ In subtraction, I am using two arguments which is initial number(first_num) for subtraction and following numbers(*args) also for subtraction.
    ◙ In multiplication,  as same as before one users inputs is taken in the string format and if this able to converted into the float it is appended in the list which is created in and if any invalid inputs are entered except block executes.
    ◙ In division, as same as from the subtraction process. It has two arguments which is numerator (first_num) and denominator (*args). First it takes input as string and try to convert float if not happen then except block executes.
    ◙ In factorials, if user enter the float, integer and negative numbers it show error. So using try and except statement blocks to prevent the code termination and print the statement for valid input.
